# ชุดข้อมูล PetID ต่างช่วงเวลา

ส่วนเก็บข้อมูลนี้แยกจากการลงทะเบียน PetID สำหรับค้นหาสัตว์หาย อยู่ในหน้า PetID และเก็บชุดภาพได้โดยไม่ต้องยินยอมฝึกโมเดล

แต่ละครั้งเก็บ 1–5 รูป เลือกมุมหน้าตรง ด้านซ้าย ด้านขวา เต็มตัว รายละเอียดจมูก หรือจุดสังเกต พร้อมวันเวลาถ่ายและแหล่งภาพ เจ้าของยืนยันว่ารูปทั้งหมดเป็นน้องตัวที่เลือก ระบบเก็บเวลารับข้อมูล/อัปโหลดแยกจากเวลาถ่ายที่เจ้าของระบุ รูปจากกล้องก็ยังมีที่มาเป็นเจ้าของระบุ ไม่อ้างว่า SDK พิสูจน์กล้องหรือวันถ่ายแล้ว

ชุดภาพเชื่อมกับ pet ID, ชนิดสัตว์ และ identity anchor จากโปรไฟล์/ทะเบียนเดิม ถ้ามีไมโครชิปจะเก็บ fingerprint ในข้อมูลส่วนตัว ไม่เปิดเลขไมโครชิปใน collector API ป้ายความน่าเชื่อถือเป็น `owner_attested_unverified` การกดยืนยันไม่ได้กลายเป็นผลตรวจ biometric หรือการรับรองโดยคลินิก

เจ้าของเลือกความยินยอม `petid_model_training` แยกเฉพาะน้องแต่ละตัว มี policy version และประวัติ revision ค่าเริ่มต้นปิด การถอนสิทธิ์ทำให้ทุกชุดที่เคยตรวจหมดสิทธิ์ภายใต้ revision เดิมทันที การเปิดใหม่ต้องตรวจภายใต้ revision ใหม่ รูปที่ถูกลบหรือไม่พร้อมใช้ทำให้ชุดนั้นต้องทบทวนใหม่

ชุดที่ส่งแล้วแก้วัน/มุมย้อนหลังไม่ได้ สร้างชุดใหม่เมื่อต้องการเพิ่มช่วงเวลา หรือลบชุดที่ไม่ต้องการ เจ้าของเห็นประวัติและโหลดชุดเก่าต่อได้ ข้อมูลและประวัติความยินยอมรวมใน personal export และลบตามการลบบัญชี

## API

- `GET /api/v1/biometric/pets/:petId/research`: ความยินยอม ประวัติชุดภาพ และสถิติวันถ่าย/มุม
- `POST /api/v1/biometric/pets/:petId/research/sessions`: ชุดภาพพร้อม `requestId`, protocol, มุม/เวลา/แหล่งรูป และการยืนยันตัวเดิม
- `POST /api/v1/biometric/pets/:petId/research/consent`: เปลี่ยนความยินยอมด้วย policy, request ID และ expected revision
- `DELETE /api/v1/biometric/pets/:petId/research/sessions/:sessionId`: ลบชุดภาพที่เจ้าของเลือก

API ตรวจ owner, รูปของน้องตัวเดียวกันและผู้เขียน, จำนวน/การใช้รูปซ้ำ, วันถ่าย และ concurrency ฝั่งฐานข้อมูล ไม่เปิดข้อมูลให้ carer, viewer หรือคลินิกเพียงเพราะมีสิทธิ์ดูแลร่วม

## ขอบเขตสำหรับ IP

ทุกชุดใหม่มีสถานะรอทบทวน ยังไม่มี endpoint อนุมัติชุดข้อมูล ส่งออกเพื่อฝึก หรือ job ฝึกโมเดลอัตโนมัติ ข้อมูลนี้เป็นฐานสำหรับขั้นต่อไป: ตรวจคุณภาพ/ภาพซ้ำ, ตรวจ identity label ด้วยหลักฐานอิสระ, จัด dataset version และ consent lineage, แบ่งชุดทดสอบตามสัตว์/เจ้าของ/ช่วงเวลา แล้ววัดการจับคู่ผิดและการปฏิเสธตัวเดิมตามขนาดฐานที่ต้องใช้จริง จำนวนรูปและวันถ่ายที่ระบุยังไม่พิสูจน์ความแม่นยำหรือการมี IP ที่รับรองแล้ว
