# ชุดข้อมูล PetID ต่างช่วงเวลา

ส่วนเก็บข้อมูลนี้แยกจากการลงทะเบียน PetID สำหรับค้นหาสัตว์หาย อยู่ในหน้า PetID และเก็บชุดภาพได้โดยไม่ต้องยินยอมฝึกโมเดล

แต่ละครั้งเก็บ 1–5 รูป เลือกมุมหน้าตรง ด้านซ้าย ด้านขวา เต็มตัว รายละเอียดจมูก หรือจุดสังเกต พร้อมวันเวลาถ่ายและแหล่งภาพ เจ้าของยืนยันว่ารูปทั้งหมดเป็นน้องตัวที่เลือก ระบบเก็บเวลารับข้อมูล/อัปโหลดแยกจากเวลาถ่ายที่เจ้าของระบุ รูปจากกล้องก็ยังมีที่มาเป็นเจ้าของระบุ ไม่อ้างว่า SDK พิสูจน์กล้องหรือวันถ่ายแล้ว

ชุดภาพเชื่อมกับ pet ID, ชนิดสัตว์ และ identity anchor จากโปรไฟล์/ทะเบียนเดิม ถ้ามีไมโครชิปจะเก็บ fingerprint ในข้อมูลส่วนตัว ไม่เปิดเลขไมโครชิปใน collector API ป้ายความน่าเชื่อถือเป็น `owner_attested_unverified` การกดยืนยันไม่ได้กลายเป็นผลตรวจ biometric หรือการรับรองโดยคลินิก

เจ้าของเลือกความยินยอม `petid_model_training` แยกเฉพาะน้องแต่ละตัว มี policy version และประวัติ revision ค่าเริ่มต้นปิด การถอนสิทธิ์ทำให้ทุกชุดที่เคยตรวจหมดสิทธิ์ภายใต้ revision เดิมทันที การเปิดใหม่ต้องตรวจภายใต้ revision ใหม่ รูปที่ถูกลบหรือไม่พร้อมใช้ทำให้ชุดนั้นต้องทบทวนใหม่

ชุดที่ส่งแล้วแก้วัน/มุมย้อนหลังไม่ได้ สร้างชุดใหม่เมื่อต้องการเพิ่มช่วงเวลา หรือลบชุดที่ไม่ต้องการ เจ้าของเห็นประวัติและโหลดชุดเก่าต่อได้ ข้อมูลและประวัติความยินยอมรวมใน personal export และลบตามการลบบัญชี

## API

- `GET /api/v1/biometric/pets/:petId/research`: ความยินยอม ประวัติชุดภาพ และสถิติวันถ่าย/มุม
- `POST /api/v1/biometric/pets/:petId/research/sessions`: ชุดภาพพร้อม `requestId`, protocol, มุม/เวลา/แหล่งรูป และการยืนยันตัวเดิม
- `POST /api/v1/biometric/pets/:petId/research/consent`: เปลี่ยนความยินยอมด้วย policy, request ID และ expected revision
- `DELETE /api/v1/biometric/pets/:petId/research/sessions/:sessionId`: ลบชุดภาพที่เจ้าของเลือก

API ตรวจ owner, รูปของน้องตัวเดียวกันและผู้เขียน, จำนวน/การใช้รูปซ้ำ, วันถ่าย และ concurrency ฝั่งฐานข้อมูล ไม่เปิดข้อมูลให้ carer, viewer หรือคลินิกเพียงเพราะมีสิทธิ์ดูแลร่วม

## ขอบเขตสำหรับ IP

ทุกชุดใหม่มีสถานะรอทบทวน เจ้าของเลือกส่งตรวจขนาด แสง ความคมชัด และภาพซ้ำ พร้อมอนุญาตส่งภาพชุดนั้นและภาพอ้างอิงให้ `gpt-6.1-sol` เปรียบเทียบลักษณะที่เห็น ผลว่าอาจเป็นตัวเดียวกันไม่ใช่ ground truth และไม่เปลี่ยนคำยืนยันเจ้าของให้เป็น biometric ที่รับรองแล้ว

ผู้ดูแลอิสระที่ยังมีสิทธิ์ตรวจได้เฉพาะชุดที่เจ้าของยังยินยอมฝึก ต้องระบุหลักฐานสแกนไมโครชิป บันทึกคลินิก หรือชุดอ้างอิงที่ตรวจด้วยหลักฐานอิสระแล้ว พร้อมตรวจความเป็นส่วนตัว รูปทุกภาพต้องผ่านเกณฑ์เบื้องต้นและผลตรวจรุ่นปัจจุบัน ห้ามอนุมัติสัตว์ของผู้ตรวจเอง การอนุมัติเป็นคำรับรองตามหลักฐานที่ผู้ตรวจทบทวน ไม่ใช่การพิสูจน์ liveness หรือการตรวจรับรองโดยห้องปฏิบัติการ

มี endpoint สร้าง manifest ฝึก/ทดสอบสำหรับผู้ดูแลที่ได้รับอนุญาต อายุ 24 ชั่วโมง ไม่รวมลิงก์ภาพ ชื่อผู้ใช้ ไมโครชิป หรือข้อมูลรักษา ตรวจสิทธิ์สดก่อนรับภาพและระหว่างฝึก/ประเมิน เมื่อถอนสิทธิ์ ลบภาพ หรือหลักฐานเปลี่ยน snapshot เดิมใช้ต่อไม่ได้ Pipeline ท้องถิ่นมีการฝึก embedding จริงและประเมินด้วย threshold จากชุด calibration เท่านั้น รายละเอียดและคำสั่งรันอยู่ใน [PETID_MODEL_PIPELINE.md](PETID_MODEL_PIPELINE.md)

จำนวนรูป วันถ่าย และผลทดสอบข้อมูลสังเคราะห์ยังไม่พิสูจน์ความแม่นยำกับสัตว์จริงหรือ IP ที่รับรองแล้ว โมเดลที่ฝึกไม่ได้เปิดใช้ค้นหาใน production อัตโนมัติ

ใช้ migrations 17–20 ไม่มี repo หรือบริการจัดเก็บใหม่ และไม่เปลี่ยน LIFF endpoint

## ตรวจภาพและหลักฐาน

- `GET/POST /api/v1/biometric/pets/:petId/research/sessions/:sessionId/checks` — เจ้าของดูผลหรือเลือกส่งตรวจครั้งหนึ่ง
- `GET /api/v1/biometric/review/queue` และ `/review/sessions/:sessionId` — ผู้ตรวจที่ได้รับอนุญาต
- `POST /api/v1/biometric/review/sessions/:sessionId` — ผลตรวจพร้อม check ID, consent revision และหลักฐานอิสระ
- `GET /api/v1/biometric/review/sessions/:sessionId/media/:mediaId` — ภาพที่ตรวจสิทธิ์วิจัยสดทั้งก่อนและหลังโหลด ไม่มีลิงก์ capability อายุยาวให้ผู้ตรวจ
- `POST /api/v1/biometric/review/datasets` — manifest ของภาพที่มีสิทธิ์ปัจจุบัน
