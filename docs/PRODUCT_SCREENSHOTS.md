# ภาพหน้าจอ Product ของชิดใจ

วันที่บันทึกภาพ: 30 ตุลาคม 2026 (Asia/Bangkok)

ภาพเหล่านี้เป็นการจับภาพ UI ที่ทำงานจริง ไม่ใช่ภาพหน้าจอที่สร้างด้วย AI หรือวาดข้อความทับ รูปใช้สำหรับหน้า `/product` ในกรอบโทรศัพท์ที่เป็นองค์ประกอบของเว็บไซต์ กรอบดังกล่าวไม่ได้เปลี่ยนแหล่งที่มาของภาพให้เป็นแอป LINE บนมือถือ

## แหล่งที่มาและคำบรรยาย

- **Care diary, Pet Passport, Memories และ PetID:** จับจาก LIFF/เว็บแอป Production ใน Chrome โดยใช้บัญชีที่เจ้าของโปรเจกต์เข้าสู่ระบบและเปิดไว้ให้ ปรับหน้าจอเป็นขนาดมือถือและเลือกภาษาไทย/อังกฤษผ่าน UI จริง
- **LINE Agent ภาษาไทย:** เป็นส่วนของข้อความตอบกลับจริงจากแอป LINE Desktop บน macOS แสดงข้อความรับเรื่อง กำลังทำงาน และการ์ดงานที่เสร็จพร้อมปุ่มเปิดผลใน LIFF คำบรรยายต้องระบุว่าเป็นภาพจาก LINE Desktop ไม่อ้างว่าเป็นภาพ LINE บนมือถือ
- **LINE Agent ภาษาอังกฤษ:** เป็นหน้าจัดการความจำของผู้ช่วยใน LIFF ภาษาอังกฤษ แสดงความสามารถด้าน memory ไม่ใช่แชตภาษาอังกฤษจาก LINE Native คำบรรยายต้องระบุว่าเป็นการตั้งค่าความจำผ่าน LIFF และไม่เรียกว่า “ข้อความตอบกลับภาษาอังกฤษจาก LINE”

ชื่อสัตว์เลี้ยง “พีโอนี” เป็นชื่อเฉพาะจากบัญชีเดิมและคงไว้ตามที่แสดงจริง แม้ UI จะเลือกภาษาอังกฤษ ไม่ได้แปลชื่อหรือดัดแปลงข้อความในภาพ

## ไฟล์ที่หน้าเว็บใช้

ไฟล์เผยแพร่อยู่ใน `frontend/owner-app/public/product/` ส่วนขนาดจริงสำหรับ `next/image` อยู่ใน `frontend/owner-app/components/product-capture-sizes.ts`

| Feature | ไทย | อังกฤษ | ขนาด |
| --- | --- | --- | --- |
| Care diary | `care-diary-th.webp` | `care-diary-en.webp` | 400 × 820 |
| Pet Passport | `passport-th.webp` | `passport-en.webp` | 400 × 820 |
| Memories | `memories-th.webp` | `memories-en.webp` | 400 × 820 |
| PetID | `petid-th.webp` | `petid-en.webp` | 400 × 820 |
| LINE Agent | `line-agent-th.webp` | `line-agent-en.webp` | ไทย 790 × 1355; อังกฤษ 368 × 726 |

## การเตรียมภาพและความเป็นส่วนตัว

- ภาพ LIFF แปลง JPEG เป็น WebP คุณภาพ 90 โดยไม่แก้ข้อความ สี หรือองค์ประกอบ UI
- ภาพ LINE ภาษาไทยครอปจากต้นฉบับด้วยกรอบ `left=730, top=375, width=790, height=1355` แล้วแปลงเป็น WebP คุณภาพ 92 กรอบนี้ตัดรายชื่อแชตอื่นและการ์ดยกเลิกที่ติดมาบางส่วนออก เหลือเฉพาะข้อความของชิดใจที่ใช้แสดง flow
- ไฟล์ LINE เต็มหน้าต่างและต้นฉบับจับภาพเก็บเฉพาะในโฟลเดอร์ `.verification/product-captures/` ที่ถูก ignore ห้ามคัดลอกภาพเต็มหน้าต่างขึ้น `public/` หรือ stage ใน Git
- ไม่แสดงข้อความสนทนาจากบุคคลอื่น รายชื่อเพื่อน ข้อมูลบัญชี รหัสผ่าน access token หรือ URL แชร์ที่มี token
- แบบฟอร์มที่เลือกแสดงไม่มีอาการ ค่ารักษา ใบเสร็จ หรือข้อความสุขภาพส่วนตัวที่กรอกไว้
- ไม่มีการเข้าสู่ระบบบัญชีใหม่ ส่งข้อความ LINE สร้างบันทึก/ไดอารี่ใหม่ หรือเปลี่ยนความยินยอมเพื่อทำภาพชุดนี้

## เกณฑ์ตรวจรับภาพ

ตรวจข้อความและรายละเอียดบนภาพจริงก่อนเผยแพร่ ภาพต้องไม่ติด UI ระหว่าง animation หรือ dialog ที่ยังเปิดไม่เต็ม และคำบรรยายต้องตรงแหล่งที่มา ไม่อ้างการทำงานที่ไม่ได้แสดง

สถานะ: ผ่านการตรวจครบ 10 ภาพ ภาพ PetID ทั้งสองภาษาจับใหม่หลัง dialog เปิดเสร็จแล้วและตรวจสถานะตรงกัน แสดงหน้าลงทะเบียน รูป 0/5 ปุ่มเลือกรูป/ถ่ายรูป และส่วนจุดสังเกตพร้อมปุ่ม AI ซึ่งยังปิดไว้ตามสถานะจริงที่ไม่มีรูป ไม่มีการกรอกหรือสร้างข้อมูลเพื่อทำภาพ
