# สื่อที่ติดตั้งบน Landing ของชิดใจ

อัปเดต 2026-10-30 — สื่อที่ผู้ใช้สร้างและส่งมา ใช้เป็นภาพประกอบการตลาด ไม่ใช่ภาพพิสูจน์ตัวตนหรือข้อมูลประเมินความแม่นยำ PetID

## ไฟล์จริง

ต้นฉบับอยู่ที่ root ของ workspace และเก็บไว้โดยไม่แก้ไข เวอร์ชันเว็บอยู่ใต้ `frontend/owner-app/public/landing/` เปิดใช้ผ่าน `frontend/owner-app/components/landing-media.ts` ไม่มีการเปลี่ยน SQL หรือ `.env`

| ตำแหน่ง | ต้นฉบับ | เวอร์ชันเว็บ | สัดส่วนจริง |
| --- | --- | --- | --- |
| Hero | `hero.mp4` | `hero.mp4` + `hero.webp` | 640×360, 16:9 |
| Diary | `story-diary.png` | `story-diary.webp` | 1448×1086, 4:3 |
| Passport | `story-passport.png` | `story-passport.webp` | 1448×1086, 4:3 |
| Follow-up | `story-followup.mp4` | `story-followup.mp4` + `story-followup.webp` | 640×360, 16:9 |
| PetID | `petid.mp4` | `petid.mp4` + `petid.webp` | 640×360, 16:9 |
| Memories | `memories.mp4` | `memories.mp4` + `memories.webp` | 360×640, 9:16 |
| Closing | `closing.png` | `closing.webp` | 1774×887, 2:1 |

เวอร์ชันเว็บรวมประมาณ 2.69 MB ลดจากต้นฉบับประมาณ 79.7% วิดีโอทั้งสี่ชิ้นใช้สตรีม H.264 เดิม ไม่เพิ่มขนาดภาพ ตัดเสียงและ metadata ออก เปิด faststart สำหรับเริ่มเล่นผ่านเว็บ วิดีโอประมาณ 10 วินาที 24 fps ภาพปกดึงจากเฟรมจริงของคลิป ส่วนภาพนิ่งแปลงเป็น WebP

## การแสดงผล

- รักษาภาพ Hero ให้เห็นแมวและสุนัขพร้อมกัน และ PetID ให้เห็นภาพเทียบด้านข้างครบ
- Memories ใช้กรอบแนวตั้งตามคลิปจริง ส่วน Closing แสดง 2:1 เพื่อไม่ตัดศีรษะเจ้าของหรืออุ้งเท้า
- มีภาพปกสำหรับทุกคลิป ใช้ภาพนิ่งเมื่อพัก motion หรือระบบตั้งลดการเคลื่อนไหว
- คลิปเล่นแบบเงียบ วนซ้ำ และหยุดเมื่อออกจากพื้นที่แสดงหรือแท็บไม่ active ท่าเริ่มและจบใกล้เคียงกัน แต่ไม่ได้ปรับแต่งให้ตรงกันทุกพิกเซล
- ยังไม่มี Hero รุ่นมือถือแยก จึงใช้ไฟล์เดียวกันในกรอบที่รักษาสัดส่วน

## การเปลี่ยนสื่อครั้งต่อไป

แทนไฟล์เว็บหรือเพิ่มชื่อไฟล์ใหม่แล้วอัปเดต registry ตรวจ desktop/mobile, ไทย/อังกฤษ, motion on/off และการเล่นวิดีโอจริงก่อน push ไม่ควรครอปวิดีโอแนวนอนเป็นแนวตั้งโดยไม่ตรวจใบหน้าทั้งสองตัวและกราฟิกด้านข้าง
